2.3. Rational functions. Let X be an affine variety. For nonempty open subsets U, V ⊆
X and f ∈OX(U), g ∈OX(V), we define (U, f) ∼(V, g) if and only if f = g on some
nonempty open subset W ⊆U ∩V. It is easy to check that this is an equivalence
relation. An equivalence class of such pairs is called a rational function on X. Let
C(X) be the set of rational functions. We define addition and multiplication on C(X)
in a usual way. Then they are well-defined, and make C(X) a C-algebra. We call C(X)
the function field of X.
Theorem 2.12. For an affine variety X, we have C(X)  F(A(X)).
Proof. For a/b ∈F(A(X)), we have a/b ∈DX(b). If a/b = 0 on a nonempty open subset
of DX(f), then a vanishes there and hence on all of X so that a = 0. This shows that
there is an injective map F(A(X)) →C(X), which is clearly a ring homomorphism.
For an open subset U ⊆X and f ∈OX(U), we may write f = a/b on DX(b) for some
a, b ∈A(X) with b , 0 by Theorem 2.4. This proves that the map is surjective and hence
an isomorphism.
