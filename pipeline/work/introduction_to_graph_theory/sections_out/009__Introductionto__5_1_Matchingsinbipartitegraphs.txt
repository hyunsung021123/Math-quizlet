5.1Matchings in bipartite graphs

Because an incidence graph is bipartite, we ﬁrst study matchings in a bipartite graph. For a
vertex set S, write N(S) :⇤–

When does an X, Y-bigraph have a matching covering X? Necessarily every S ✓X has at
least |S| available neighbors. Hall’s theorem says that these are the only obstructions.

Theorem 5.2(Hall’s theorem, 1935). In an X, Y-bigraph, there exists a matching covering X if
and only if |N(S)| ≥|S| for all S ✓X.

Proof. If a matching covers X, its edges inject every S ✓X into N(S), so |N(S)| ≥|S|.

We use induction to prove suﬃciency. When |X| 1, the claim is immediate. Assume
|X| > 1 and consider two cases.

If |N(S)| > |S| for every nonempty proper subset S of X, choose x 2 X and y 2 N(x). The
graph G −{x, y} satisﬁes Hall’s condition: the neighborhood of a proper subset of X loses at
most the vertex y. Induction gives a matching covering X \ {x}, and adding xy completes the
matching.

If |N(S)| ⇤|S| for some nonempty proper set S ✓X, let G1 be the graph induced by S[N(S)
and let G2 be the graph induced by V(G) \ (S [ N(S)).

The size of a matching is bounded by another natural concept.

Deﬁnition 5.6. A vertex cover is a set of vertices containing at least one endpoint of every
edge. The minimum size of a vertex cover is denoted by β(G).

Theorem 5.7(König-Egerváry Theorem, König 1931). If G is bipartite, then ↵0(G) ⇤β(G).

Proof. Let G be an X, Y-bigraph. Every vertex covers at most one edge in a matching, so β(G) ≥
↵0(G). By the above corollary, there exists a subset T of X such that ↵0(G) ⇤|X| −|T| + |N(T)|.
Since N(T) [ (X −T) is a vertex cover, β(G) |N(T)| + |X −T| ⇤↵0(G).
⇤

Deﬁnition 5.8. An edge cover of G is a set of edges that cover all vertices of G. We use β0(G)
to denote the minimum size of an edge cover.

The parameter β0(G) is deﬁned only when G has no isolated vertices.
Since ↵0 ⇤β for bipartite graphs, one may ask whether ↵⇤β0 also holds.
The following lemma is left as an exercise.

Lemma 5.9. In an n-vertex graph G, a vertex subset S is an independent set if and only if V(G)\ S
is a vertex cover. Hence ↵(G) + β(G) ⇤n.

The other two parameters, ↵0 and β0, satisfy a similar identity.

Theorem 5.10(Gallai, 1959). If G is an n-vertex graph with no isolated vertices, then ↵0(G) +

β0(G) ⇤n.

Proof. We ﬁrst prove β0(G) n −↵0(G). It is enough to construct an edge cover of size n −↵0(G).
Let M be a maximum matching in G. For each vertex uncovered by M, add one incident edge.
This uses one edge for each vertex uncovered by M, while each edge in M covers two vertices,
so the resulting edge cover has size n −|M|. This proves β0(G) n −↵0(G).

We now prove ↵0(G) ≥n −β0(G). Let L be a smallest edge cover. If both endpoints of an
edge e lie in other edges in L, then L −e is a smaller edge cover, a contradiction. Hence, each
component of L has at most one vertex with degree larger than 1, hence a star. If there are
k such stars, then |L| ⇤n −k, since L has one edge for each vertex except the centers of the

5.2Matchings in general graphs

Hall’s condition does not extend directly to general graphs. For example, K2n+1 has the
largest possible neighborhoods but cannot have a perfect matching because its order is odd.
More generally, disjoint unions of odd cliques illustrate the parity obstruction. The following
deﬁnitions capture the relationship between matching number and this obstruction.

Deﬁnition 5.11. For k 2 N, a k-factor in a graph G is a k-regular spanning subgraph of G.
An odd component is a component of odd order. We write o(G) for the number of odd
components of G.

Hall’s theorem gives a set S ✓X such that ↵0(G) ⇤|X| −|S| + |N(S)|. If we delete T :⇤N(S),
every vertex of S becomes isolated. Thus, when |S| > |T|, every matching leaves at least
|S| −|T| vertices of S uncovered.

The same idea extends to general graphs. For any T ✓V(G), every matching leaves at least
o(G −T) −|T| vertices uncovered (a vacuous bound when this quantity is negative). As in
Hall’s theorem, this turns out to be the correct obstruction. First consider a small example.
