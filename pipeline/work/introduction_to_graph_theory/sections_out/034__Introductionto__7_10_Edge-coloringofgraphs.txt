7.10Edge-coloring of graphs

For some problems, the pairwise relationships between objects are the main concern. For
example, let vertices represent people and let an edge join each pair that must meet. If colors
represent time slots, then two meetings involving the same person cannot receive the same
color. This motivates edge-coloring.

Deﬁnition 7.37. A k-edge-coloring of a loopless multigraph G is a labeling of its edges
from a set of k colors; it is proper if incident edges receive distinct colors. We call G
k-edge-colorable if it has a proper k-edge-coloring, and the edge-chromatic number or
chromatic index χ0(G) is the minimum such k.

Every color class of a proper edge-coloring is a matching. A loop cannot belong to a
matching, which is why edge-coloring is restricted to loopless multigraphs. Because parallel
edges must receive distinct colors, edge-coloring behaves diﬀerently for multigraphs and
simple graphs.

For loopless multigraphs, it is not diﬃcult to see that χ0(G) ⇤χ(L(G)), where L(G) is the
line graph of Deﬁnition 6.20.

Deﬁnition 7.39. A graph G is Class 1 if it is ∆(G)-edge-colorable, and Class 2 otherwise. A
decomposition of the edge set of a multigraph into perfect matchings is a 1-factorization.
A multigraph that has such a decomposition is 1-factorable.

With this deﬁnition, a regular graph is Class 1 if and only if it is 1-factorable. A regular
graph of odd order has no 1-factor, so it is Class 2 when its degree is positive. By contrast, the
complete graph K2n and the d-dimensional hypercube Qd are Class 1. The Petersen graph in
Figure 7.2 is cubic and Class 2: it has no 3-edge-coloring.

Here is a short reason that the Petersen graph is Class 2. A Hamiltonian cycle would use an
even, positive number of spokes, hence either two or four. With two spokes, their labels would
have to be consecutive on both the outer pentagon and the inner pentagram, requiring their
diﬀerence modulo 5 to be both ±1 and ±2. With four spokes, the missing spoke forces the
selected outer and inner edges to close into two disjoint 5-cycles, not one spanning cycle. Thus
the Petersen graph is non-Hamiltonian. Since it has girth 5, every spanning 2-factor therefore
consists of two 5-cycles. But in a 3-edge-coloring of a cubic graph, the union of any two color
classes is a spanning 2-factor all of whose cycles alternate between the two colors and hence
have even length. This contradiction proves that no 3-edge-coloring exists.

7.11[A] Perfect graphs

Proper vertex coloring and edge-coloring both have the following form: partition a set S into
the fewest classes such that no class contains two elements from any of the sets Q1, . . . , Qt
contained in S. For vertex coloring, S is the vertex set and the Qi are cliques (or simply edges).
For edge-coloring, S is the edge set and the Qi are sets of edges having a common endpoint.

From this viewpoint, the coloring problem is a covering problem rather than a partition
problem. It is enough to ﬁnd suitable classes whose union covers all the elements, because we
can arbitrarily delete repeated elements from the classes to obtain a partition.

The corresponding packing problem asks for the largest set of elements no two of which
can belong to the same color class. For vertex coloring, such sets are cliques. For edge-coloring
of a graph, they are sets of pairwise incident edges, which form a star or a triangle. Each color
class covers at most one element of such a set, so the size of every packing is a lower bound
for the number of color classes.

For the paired optimization problems considered here, this comparison is called weak
duality: every feasible solution of the minimization problem has value at least that of every
feasible solution of the maximization problem.

A min-max relation is a statement that equality holds for the answers to two dual integer
optimization problems for some family of instances. For example, the equality ↵0(G) ⇤β(G) for
bipartite graphs is a min-max relation. Often, such a relation leads to eﬃcient algorithms for
the corresponding optimization problems. Min-max relations do not always hold for coloring
and edge-coloring, but they do hold for some special graph classes.
