If such a map exists, then G and H are isomorphic, written G ' H. An unlabeled graph is an
isomorphism class of graphs.

Graph isomorphism is an equivalence relation. In informal statements we usually identify
isomorphic graphs.

Deﬁnition 2.3. A graph H is a subgraph of G if V(H) ✓V(G) and E(H) ✓E(G). It is spanning
if V(H) ⇤V(G). For U ✓V(G), the induced subgraph G[U] has vertex set U and contains
every edge of G with both endpoints in U.

We write G −U :⇤G[V(G) \ U] for vertex deletion and G −F for the spanning subgraph
obtained by deleting an edge set F. For a single vertex or edge, we abbreviate these as G −v
and G −e. If u, v are distinct nonadjacent vertices, G + uv is obtained by adding the edge uv.
For disjoint vertex sets S, T, let eG(S, T) be the number of edges between them; a subgraph in
either argument stands for its vertex set.

Let G ⇤([4], {12, 23, 34, 41, 13}). The four-cycle with edge set {12, 23, 34, 41} is spanning
but not induced, because it omits the edge 13. In contrast, G[{1, 2, 4}] has edge set {12, 14}, so
it is induced but not spanning.
